MännerRecht AI — v0.1
This is a free, static prototype of a German legal-information assistant.
Run it
No installation is required. Open index.html in a browser.
For free hosting, upload the folder to a static host such as GitHub Pages or Cloudflare Pages.
What this version does
Responsive legal-assistant interface
Topic selection
Multilingual UI selector (interface scaffold)
Basic question routing
Official German legal-source links
Legal-information disclaimer
What it deliberately does NOT do yet
It does not claim to be a lawyer.
It does not provide legal representation.
It does not yet perform live retrieval of the complete German legal corpus.
It does not yet connect to a paid or local AI model.
It does not yet guarantee that an answer reflects the law on a particular date.
